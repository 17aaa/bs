# 学生创意成果NFT交易系统 - 数据库表结构文档

## 数据库概述

- **数据库名称**: creativenft_db
- **数据库类型**: MySQL 8.0+
- **字符集**: utf8mb4
- **排序规则**: utf8mb4_unicode_ci

---

## 表结构总览

| 序号 | 表名 | 说明 |
|------|------|------|
| 1 | users | 用户表 |
| 2 | wallets | 用户钱包表 |
| 3 | nft_assets | NFT资产表 |
| 4 | nft_versions | NFT版本历史表 |
| 5 | market_orders | 市场订单表 |

## 1. 用户表 (users)

### 建表语句

```sql
CREATE TABLE `users` (
  `user_id` bigint NOT NULL AUTO_INCREMENT,
  `username` varchar(100) COLLATE utf8mb4_unicode_ci NOT NULL,
  `password` varchar(255) COLLATE utf8mb4_unicode_ci NOT NULL,
  `email` varchar(100) COLLATE utf8mb4_unicode_ci DEFAULT NULL,
  `phone` varchar(20) COLLATE utf8mb4_unicode_ci DEFAULT NULL,
  `avatar` varchar(500) COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '头像URL',
  `school` varchar(100) COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '学校',
  `major` varchar(100) COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '专业',
  `bio` varchar(500) COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '个人简介',
  `gmt_create` timestamp NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`user_id`),
  UNIQUE KEY `username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 字段说明

| 字段名 | 类型 | 可空 | 默认值 | 说明 |
|--------|------|------|--------|------|
| user_id | bigint | NO | AUTO_INCREMENT | 用户ID（主键） |
| username | varchar(100) | NO | - | 用户名（唯一） |
| password | varchar(255) | NO | - | 密码（加密存储） |
| email | varchar(100) | YES | NULL | 邮箱 |
| phone | varchar(20) | YES | NULL | 手机号 |
| avatar | varchar(500) | YES | NULL | 头像URL |
| school | varchar(100) | YES | NULL | 学校 |
| major | varchar(100) | YES | NULL | 专业 |
| bio | varchar(500) | YES | NULL | 个人简介 |
| gmt_create | timestamp | YES | CURRENT_TIMESTAMP | 创建时间 |
| phone | varchar(20) | YES | NULL | 手机号 |
| gmt_create | timestamp | YES | CURRENT_TIMESTAMP | 创建时间 |

## 2. 用户钱包表 (wallets)

## 3. NFT资产表 (nft_assets)

### 建表语句

```sql
CREATE TABLE `nft_assets` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '主键 ID',
  `token_id` bigint NOT NULL COMMENT 'Token ID（链上）',
  `contract_address` varchar(42) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '合约地址',
  `owner_address` varchar(42) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '所有者地址',
  `creator_address` varchar(42) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '创作者地址',
  `name` varchar(200) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '作品名称',
  `description` text COLLATE utf8mb4_unicode_ci COMMENT '作品描述',
  `category` varchar(50) COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '分类',
  `current_metadata_hash` varchar(100) COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '当前元数据哈希（IPFS CID）',
  `current_version` int DEFAULT '1' COMMENT '当前版本号',
  `royalty_fee` int DEFAULT '500' COMMENT '版税比例（万分比）',
  `royalty_recipient` varchar(42) COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '版税接收地址',
  `status` tinyint DEFAULT '1' COMMENT '状态：1-正常 2-下架 3-冻结',

```

## 系统状态值说明

### NFT状态 (nft_assets.status)
- 1: 正常 - NFT可以交易
- 2: 下架 - NFT已从市场下架
- 3: 冻结 - NFT被冻结，不可交易

### 订单状态 (market_orders.status)
- 1: 活跃 - NFT正在市场出售
- 2: 已售 - NFT已成功出售
- 3: 取消 - 卖家取消订单
- 4: 过期 - 订单已过期

### 订单类型 (market_orders.order_type)
- 1: 固定价格 - 一口价销售
- 2: 荷兰拍卖 - 价格随时间递减
- 3: 报价 - 买家报价

### 粉丝代币状态 (fan_tokens.status)
- 1: 正常 - 代币正常运行
- 2: 暂停 - 公募/交易暂停
- 3: 结束 - 项目结束
